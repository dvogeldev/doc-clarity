# Defaults

The brief wins when a field is set. Use these when the brief leaves a field empty.

- audiences: `both`
- ste-human: `no`
- climb-to: `writing`
- readers: a person who must do the task after one read
- diagrams: one claim in each figure
- web: one self-contained HTML file, no brand colors
- video: write the narration and the shots; render only with a tool this session already has; do not store an API key
